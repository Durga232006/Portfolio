# Durgadevi K Portfolio Website

Responsive futuristic blue portfolio with improved spacing, larger typography, and cleaner alignment.

## Open
Open `index.html` in a browser, or run `python -m http.server 8000` from this folder.

## Personalize
- Replace `assets/profile.jpg` with your professional photo.
- Add your resume as `assets/resume.pdf`.
- Add the airline project screenshot as `assets/airline.jpg`.
- Replace `YOUR_EMAIL@example.com` in `index.html` with your email.
- Update internship dates and certification placeholders in `index.html`.

Contact section remains removed, KURU KALAN remains excluded, and project cards have no Live Demo/GitHub buttons.
